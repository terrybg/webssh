# WebSSH 使用帮助

浏览器里的轻量 **SSH 终端 + SFTP 文件管理** 工具。本页按功能模块说明怎么用，并汇总快捷键。

入口示例：`http://localhost:9092/webssh/page/index.html`  
默认端口：**9092**

---

## 1. 桌面首页

首页是图标桌面（不再使用旧版会话表格）。

| 图标 / 操作 | 作用 |
|-------------|------|
| **添加服务器** | 新建连接：名称、IP、端口、用户名、密码 |
| **通用命令** | 维护所有服务器共用的命令库 |
| **帮助** | 打开本帮助窗口 |
| **服务器图标 · 单击** | 弹出菜单：**远程**（SSH）/ **文件**（SFTP） |
| **服务器图标 · 右键** | **修改** / **删除** / **常用命令** |

提示：会话密码保存在服务端本地 `data/sessions.json`，请勿把服务裸暴露到公网。

---

## 2. 远程（SSH 终端）

1. 单击服务器图标 → **远程**
2. 打开浮动终端窗（xterm），可输入命令、使用全屏类程序（vim、top、看日志等）
3. 工具栏可切换 **编码**（UTF-8 / GBK 等）、**主题**、刷新连接
4. 左侧可展开 **快捷键 / 常用命令** 面板：搜索、按「全部 / 通用 / 本机」过滤，点击即可发送到终端

### 命令提示与收集

- 输入时会出现类似 IDEA 的命令提示；仅在用 **↑↓ 选中提示项** 后，Tab / 回车才会套用提示（避免抢走 shell 自身补全）
- 可在本机常用命令里开启 **回车自动收集**（按会话、有条数上限）

关闭终端窗口 **不会** 注销后台 SSH 会话，可再次打开继续用。

---

## 3. 文件（SFTP）

1. 单击服务器图标 → **文件**
2. 打开类资源管理器窗口：左侧目录树 + 收藏，中间文件列表，顶部地址栏与工具

### 常用操作

| 操作 | 说明 |
|------|------|
| 浏览 | 双击文件夹进入；地址栏空白处单击可编辑路径，回车跳转 |
| 查看方式 | 详细信息 / 大图标（图片可缩略图）；Ctrl+滚轮可在详情与图标间缩放 |
| 上传 | 工具栏上传，或把本地文件拖进窗口；有当前文件 + 合计进度 |
| 下载 | 选中文件右键 → 下载 |
| 预览 | 双击或空格预览支持的类型；Esc 关闭预览 |
| 搜索 | 顶部按文件名搜索；可选向下搜索的目录层数 |
| 收藏 | ★ 收藏当前目录，左侧快速打开 |
| 压缩 / 权限 / 属性 | 右键菜单 |

### 复制、移动与跨服务器

- **同一服务器**：拖拽默认为 **复制**；按住 **Shift** 拖拽为 **移动**
- **跨服务器**（两个文件窗、不同机器）：仅支持 **复制**；会弹出与上传类似的 **双进度条**
- 也可使用 Ctrl+C / Ctrl+X / Ctrl+V（同服务器剪贴板）

### 路径记忆

- 刷新页面后，已打开过的文件窗会尽量 **还原到当时目录**（例如当时在 `/data`，刷新后仍进 `/data`）
- 窗口布局（位置、停靠、Snap）也会一并恢复

## 4. 窗口：浮动 / 停靠 / Snap

| 能力 | 怎么用 |
|------|--------|
| **浮动窗** | 默认打开方式；拖标题栏移动，拖边角改大小 |
| **▤ 左侧停靠** | 点标题栏 ▤，窗进入左侧多列停靠；可拖分割条调宽；再点 ▤ 或拖出停靠区恢复浮动 |
| **边缘 Snap** | 拖标题栏到左/右缘 → 半屏；拖到四角 → 四分之一；松手前有半透明预览 |
| **布局板** | 鼠标悬停 **最大化** 按钮，弹出 Win11 风格布局（左右、上下、四格等），点格落入槽位 |
| **Snap Assist** | 占槽后若还有空槽，可点选其它已开窗填入；Esc 或点空白取消 |
| **任务栏** | 底部：左键聚焦 / 最小化；右键：**还原 / 最小化 / 最大化 / 关闭** |

布局保存在浏览器 `localStorage`；服务重启后需重新登录会话，文件窗会自动重连（若凭证仍有效）。

## 5. 通用命令与本机命令

| 类型 | 入口 | 说明 |
|------|------|------|
| **通用命令** | 桌面「通用命令」 | 所有会话共享；首次可从内置字典导入 |
| **本机常用命令** | 服务器图标右键 → 常用命令 | 按会话隔离；可配自动收集 |

终端快捷键面板会合并展示通用 + 当前会话本机命令。

## 6. 快捷键一览

### 6.1 文件窗（焦点在文件窗内，且不在输入框中）

| 快捷键 | 功能 |
|--------|------|
| **F5** | 刷新当前目录 |
| **F2** | 重命名 |
| **Delete** | 删除 |
| **Enter** | 打开 |
| **Backspace** / **Alt+↑** | 上级目录 |
| **Alt+←** / **Alt+→** | 后退 / 前进 |
| **Ctrl+L** | 聚焦地址栏编辑路径 |
| **Ctrl+A** | 全选 |
| **Ctrl+C** / **Ctrl+X** / **Ctrl+V** | 复制 / 剪切 / 粘贴 |
| **Ctrl+Z** | 撤销最近一次重命名（若支持） |
| **Ctrl+Shift+N** | 新建文件夹 |
| **空格** | 预览 / 关闭预览（可预览文件） |
| **Esc** | 关闭右键菜单、预览、地址栏编辑等 |
| **↑ / ↓** | 在列表中移动选中项 |
| **Shift+点击** | 范围多选 |
| **Ctrl+点击** | 跳选 |
| **Shift+拖拽**（同服务器） | 移动（默认拖拽为复制） |
| **Ctrl+滚轮** | 详情 ↔ 大图标缩放 |
| **Shift+F10** / **菜单键** | 打开右键菜单 |

地址栏：**回车** 跳转，**Esc** 取消编辑。

### 6.2 桌面与窗口

| 快捷键 | 功能 |
|--------|------|
| **Esc** | 关闭桌面弹出菜单；取消 Snap Assist |
| 任务栏右键 | 还原 / 最小化 / 最大化 / 关闭 |

### 6.3 终端窗

终端内按键由远程 Shell 处理（与本地 xterm 一致）。  
使用左侧 **快捷键面板** 点击命令发送；命令提示用 **↑↓** 选择后再 **Tab / 回车** 应用。

## 7. 常见问题

**提示「未登录或会话已过期」**  
服务重启后内存登录态会清空。关闭文件/终端窗再从桌面重新打开即可；新版本会尝试自动重新登录。

**列出目录失败：Permission denied**  
当前账号对目标路径无权限。换到有权限的目录（如 `/data`、家目录）。刷新后应回到你上次浏览的路径，而不是强制进 `/root`。

**跨服务器拖文件**  
两个文件窗分别连不同服务器，拖过去即为复制，并显示进度。

**布局刷新后没了**  
确认浏览器未清站点数据；且当时窗口是打开状态被保存的（关掉的窗不会复活）。

